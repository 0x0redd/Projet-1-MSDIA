Qu'est-ce que l'apprentissage supervisé ?

On apprend une fonction qui relie des entrées (features) à des étiquettes à partir d'exemples annotés. Un modèle est d'abord entraîné, puis utilisé pour prédire l'étiquette de données inédites.

01

Arbres de décision

Une fonction à valeurs discrètes représentée comme une suite de tests.

  • Nœud — test sur la valeur d'un attribut.
  • Branche — une réponse possible au test.
  • Feuille — la classe / valeur retournée.

Un chemin racine → feuille est une conjonction de contraintes ; l'arbre entier est une disjonction de ces chemins (règles si–alors).

★
Objectif : le plus petit arbre cohérent avec les exemples — plus simple, meilleure généralisation, moins de surapprentissage.

Choisir le meilleur attribut

Une bonne caractéristique sépare les exemples en sous-ensembles aussi purs que possible (idéalement tout positifs ou tout négatifs). On teste d'abord l'attribut le plus informatif.

02

Mesures de sélection d'attribut

Quantifier la pureté pour décider où découper.

Entropie

Mesure l'incertitude : maximale pour une distribution uniforme, nulle pour un ensemble pur.

H(S) = − Σ pi log2 pi

Pour 12 restaurants avec p = n = 6 : H(S) = 1.

Gain d'information

Gain(S,A) = H(S) − Σ (|Si|/|S|) · H(Si)

On retient l'attribut de gain maximal.

!
Biais du gain d'information : il favorise les attributs à nombreuses valeurs (un identifiant séparerait parfaitement les données mais ne généralise pas).

Gain ratio

Normalise le gain par l'information intrinsèque du découpage, pénalisant les attributs à beaucoup de valeurs.

GainRatio = Gain(S,A) / SplitInfo(S,A)

Impureté de Gini

Probabilité qu'un exemple tiré au hasard soit mal étiqueté. On choisit le Gini le plus faible.

G(S) = 1 − Σ pi2

Surapprentissage & élagage

  • Pré-élagage — arrêter la croissance tôt.
  • Post-élagage (souvent meilleur) — développer puis couper.

Reduced error pruning : remplacer une branche par une feuille (classe majoritaire), ne garder l'élagage que s'il améliore la performance sur un ensemble de validation ; itérer.

03

Régression linéaire

Ajuster une droite à des entrées continues par les moindres carrés.

hw(x) = w1 x + w0

On cherche les poids qui minimisent la perte quadratique :

J(w) = Σ ( yj − hw(xj) )2 ;  w* = argmin J(w)

Optimale pour un bruit gaussien (justification de Gauss).

Descente de gradient

wi ← wi − α · ∂Loss/∂wi
  • α (taux d'apprentissage) : trop grand → divergence, trop petit → lent.
  • Batch GD — tous les exemples par itération : stable mais coûteux.
  • SGD — un exemple à la fois : rapide, économe, échappe aux minima locaux.
!
Régularisation : on ajoute un terme de complexité Loss′(h) = Loss(h) + λ · Σ wi2. Un λ fort donne un modèle plus simple ; on choisit λ par validation croisée k-fold.
04

Classifieurs linéaires & régression logistique

Tracer une frontière, puis la transformer en probabilité.

Une frontière linéaire sépare deux classes linéairement séparables ; la prédiction est binaire :

hw(x) = 1 si Σ wi xi > 0, sinon 0

Apprentissage par règle du perceptron (SGD) : les poids ne bougent que sur les exemples mal classés.

Régression logistique

Le seuil dur ignore l'incertitude. La fonction logistique, dérivable partout, renvoie une probabilité :

hw(x) = 1 / (1 + e−w·x)
wi ← wi + α(y−h)·h·(1−h)·xi

Perte d'entropie croisée (log loss)

J(w) = −(1/N) Σ [ y log(h) + (1−y) log(1−h) ]
  • Convexe pour la régression logistique → pas de minima locaux.
  • Pénalise fortement les erreurs faites avec confiance.
  • Mieux adaptée aux probabilités que la MSE.
